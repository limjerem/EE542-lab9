# EE542 Lab 9

A web group chat and ADS document assistant using FastAPI, MySQL, FAISS,
and OpenAI-powered retrieval with conversation memory.

Part 1 is in `groupchat_app_src/`; Part 3 is in `embedding/` and `lab9_core/`.
See [setup](docs/SETUP.md) and [validation](docs/VALIDATION.md).

Part 4 is the final **ADS Study Companion** website and Android TWA, with a
curated ADS 2011 collection and persistent per-user study conversations.
See [Part 4 setup, sources and verification](PART4.md). Start locally with
`scripts/start_part4.ps1`; the study app is at `http://localhost:8000/ads/`.

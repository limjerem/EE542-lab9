# EE542 Lab 9

An ADS/RF study assistant combining shared web chat, document uploads,
MySQL storage, cached retrieval, and source-cited local Llama answers.

Web integration is in `groupchat_app_src/`; standalone RAG is in `embedding/`.
Local Word2Vec and custom histogram experiments are in `part5/`.
See [setup](docs/SETUP.md), [interfaces](docs/PART4_INTERFACES.md), and
[validation](docs/PART4_VALIDATION.md); see [Part 5](docs/PART5.md) for experiments.
